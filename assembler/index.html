Voltere Firmware C-Subset: Reference Guide

Welcome to the Voltere 8-Bit Architecture. Because this is a custom bare-metal processor with a strict 256-instruction memory depth and a specialized 27-opcode ISA, the compiler transpiles a strict subset of embedded C directly into hardware assembly.

1. Supported Data Types

All variables are mapped directly to the hardware's 8 general-purpose registers (R0-R7).

  • uint8_t (Standard unsigned 8-bit integer)
  • int8_t (Signed 8-bit integer)
  • int (Treated as 8-bit in this architecture)

2. Memory & Hardware Pointers

You can read and write to the 256-byte Data RAM and memory-mapped hardware peripherals.

  • RAM Access: MEM[0x10] = 255; or uint8_t val = MEM[0x20];
  • Direct Hardware Pointers: *(volatile uint8_t*)0xFF = 128;
  • Pointer Cross-talk: *(volatile uint8_t*)0xFF = *(volatile uint8_t*)0xFE;

3. Supported Operations

The ALU supports single-operation math and bitwise logic per line.

  • Arithmetic: +, -, *
  • Bitwise: &, |, ^, <<, >>
  • Compound Assignment: +=, -=, *=, &=, |=, ^=, <<=, >>=
  • Iterators: ++, --
Note on Math: Complex nested equations like a = (b + c) * d; are not supported. Break them into sequential steps.

4. Control Structures

The compiler dynamically calculates two's complement PC-relative branching for:

  • If / Else: if (x == 5) { ... } else { ... }
  • While Loops: while (x < 10) { ... }
  • Do-While Loops: do { ... } while (x != 0);
  • For Loops: for (int i = 0; i < 10; i++) { ... }

5. Functions & Exceptions

  • Main Wrapper: void main() { ... } (Required entry point)
  • Custom Functions: void my_routine() { ... } (Zero-parameter routines only)
  • Exception Service Routine: void __attribute__((interrupt)) ISR() { ... } (Maps to vector 0x80)

6. Preprocessor Macros & Hardware Intrinsics

  • Macros: #define PWM_OUT (*(volatile uint8_t*)0xFF)
  • Inline Assembly: __asm__("TRAP"); or __asm__("HALT");
  • Coprocessor 0 Read: uint8_t cause = __builtin_mfc0(0);
